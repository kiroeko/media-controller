# 嘉立创 STEP 保存问题与本次验证

本机：嘉立创 EDA 专业版 4.1.60，SOLIDWORKS 2026 SP0.0；2026-09-27 实测。

用户遇到的现象是 STEP 能导入、能显示，但保存时报 `.step.SLDASM` 已损坏。报错对象是导入过程生成的装配体；单凭这个提示不能认定原始 STEP 的几何损坏。

## 本工程怎么打开

直接打开 `../cad/Music_Controller.SLDASM`。载板已是 `REF_Carrier.SLDPRT` 独立实体零件，主控也是独立的 `REF_RP2350_Official.SLDPRT`。整机不需要重新导入 STEP，也不依赖原 Pictures 或 Windows Temp 目录。

## 以后导入新载板

1. 在嘉立创打开 PCB，选择 **文件 → 导出 → 3D 文件**。
2. 选择 **STEP**，保留 PCB、元件模型、3D 体。做外壳尺寸参考时，可关闭丝印和信号层线路；本次新样本使用 **质量优先**。
3. 在 SOLIDWORKS 关闭之前导入的那份 STEP 文档。
4. 进入 **工具 → 选项 → 系统选项 → 导入**，取消 **启用 3D Interconnect**，然后重新打开 STEP。
5. 若导入结果是装配体，选择 **文件 → 另存为 → SOLIDWORKS 零件（*.SLDPRT）**，保留全部零部件；不要只保留外表面。
6. 关闭导入文档，再打开保存的 `.SLDPRT`，确认完整载板和连接器都在，并再次保存。
7. 将验证过的 `.SLDPRT` 插入外壳装配体，核对位置和孔距。

独立零件适合作为外壳尺寸参考。PCB 修改后要重新导入并替换参考件，它不会自动跟随原 STEP 更新。测试结束已恢复本机原来的导入设置；若按上述流程操作，仍需要先取消 3D Interconnect。

## 实测结果

| 输入／方式 | 保存结果 | 关闭文档后重开与再次保存 |
|---|---|---|
| 原始 `3D_PCB1_2026-09-27.step`；关闭 3D Interconnect；另存独立零件 | 成功，0 错误、0 警告 | 成功；11 个实体，无外部依赖 |
| 新导出 `Carrier_Quality_NoSilk.step`；质量优先；开启 3D Interconnect；另存装配体副本 | 成功，0 错误、0 警告 | 成功，0 错误、0 警告 |
| 同一个新 STEP；关闭 3D Interconnect；另存独立零件 | 成功，0 错误、0 警告 | 成功；11 个实体 |

测试通过不表示已经证明原报错的唯一原因，也不表示所有导出组合都已测试。新样本的链接装配体在本次测试中未复现报错；正式工程仍使用无外部依赖的原生零件。临时测试装配体没有放入正式 `cad` 目录。

另查出旧的 `Enclosure_Smooth_20deg_v2.SLDASM` 含指向 `AppData/Local/Temp/swx45500/IC~~` 的 RP2350 STEP 装配体引用，所以没有按“v2 看起来更新”把它选作正式版本。

检查记录已合并到 `VERIFICATION.txt`。临时测试模型、重复 STEP 和旧装配体已按要求删除；当前工程需要的几何全部保留在 `../cad` 的原生零件中。
